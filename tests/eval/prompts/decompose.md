# 把会议纪要拆成单条陈述（固定提示，见 docs/prereg-claims.md 第 2 节）

输入：一份会议纪要（Markdown）。
输出：JSON 数组，每个元素是一条“单条陈述”：

```json
{"text": "...", "type": "决定|待办|负责人|期限|数字|名称|状态|观点", "time_hint": "00:05:31 或 05:31 或 null", "who_hint": "纪要里写的人（说话人N / 人名 / 发言人N），没有就 null", "src": "这条来自纪要原文的哪一句（原文照抄，不超过 60 字）"}
```

规则：
1. 每条只说一件可以拿录音核对的事。一句话里有多个事实（比如“A 负责 X，下周三前完成，预算 500 元”）就拆成多条：负责人一条、期限一条、数字一条。
2. 用陈述句改写，主语写清楚，但不得增加原文没有的信息，不得改动数字、人名、术语的写法（原文写错了也照抄）。
3. type 按这条陈述的核心可核对点选一个：
   - 决定：会上定下来的做法、规则、方向；
   - 待办：某人或团队要去做的事；
   - 负责人：某事由谁负责、谁提出、谁说的；
   - 期限：时间点、时长、截止日期；
   - 数字：金额、比例、数量、次数、排名等；
   - 名称：人名、系统名、工具名、平台名、术语本身是核对点；
   - 状态：某项工作的进展、完成情况、存在的问题；
   - 观点：某人的看法、判断、担忧。
4. time_hint：纪要在这条附近给出的时间戳（[00:05]、00:05:31 等），原样照抄最近的那个；没有就 null。
5. 不拆：标题、免责声明、“内容如下”这类过渡句、章节标题本身。
6. 只输出 JSON 数组，不要任何解释。
