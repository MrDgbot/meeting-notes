# 独立提取会上的决定和待办（固定提示，见 docs/prereg-claims.md 第 6 节）

输入：一段会议（连续若干个 30 秒窗口）的多引擎转写，读法同 judge.md。你没有看过任何纪要。
任务：找出这段里会上**明确定下来的决定**和**明确的待办**（有人要去做的具体事情）。只要原话里确实说了的；闲聊、设想、反问、没有落定的讨论不算。

每条输出：
```json
{"kind": "决定|待办", "what": "做什么 / 定了什么（一句话，具体）", "who": "谁负责或谁提出（原话里的人名或称呼；只知道说话人编号就写 '产品当时说话人N'；不知道就 null）", "when": "期限（原话里的，没有就 null）", "windows": ["W0123"], "quote": "最关键的一句原话（注明引擎，不超过60字）"}
```
关键点按跨厂商多数为准（同 judge.md）。只输出 JSON 数组；这段里没有就输出 []。
